# Portfolio Page

My personal website: a single, responsive HTML page with light and dark themes that follow the visitor's device setting.

## Built with
HTML and CSS. It has no build step and no JavaScript, so it loads fast and is easy to edit.

## Run it
Open `index.html` in any browser.

## Publish it free with GitHub Pages
1. Upload `index.html` to this repository.
2. Go to **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and the `/ (root)` folder, then save.
4. After a minute your site is live at `https://YOUR-USERNAME.github.io/portfolio/`.

## Customise
- Replace every `YOUR-USERNAME` with your GitHub username.
- Add new projects by copying an `<article class="project">` block.
- Change the colours in the `:root` block at the top of the `<style>` section.

## What I practised
- Semantic HTML and accessibility (headings, link focus, colour contrast)
- Responsive layout without frameworks
- CSS variables and `prefers-color-scheme`
